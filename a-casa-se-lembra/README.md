# A CASA SE LEMBRA

Jogo de terror psicológico em primeira pessoa, para navegador, feito sob medida para a Rafaela —
a partir de dois vídeos da casa da família.

## Como jogar

1. Abra o arquivo `index.html` com dois cliques (Chrome, Edge ou Firefox atualizados).
   Não precisa de servidor nem de internet.
2. Clique em **Novo jogo**. Use fones de ouvido.

Se preferir servir por HTTP: `npx serve .` dentro desta pasta e abra o endereço mostrado.
